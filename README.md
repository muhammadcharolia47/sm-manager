# SM Manager
Private offline-first Android business manager for garment manufacturing.

This initial build is the black/gold UI foundation. The project is ready to be compiled by a standard Android/Gradle CI environment.

Targeted features for subsequent builds:
- Sales/invoices, image/PDF sharing
- Customer/supplier ledgers
- Credit periods: immediate, 5, 10, 15, 20, 25, 30, 45, 60 days
- Product/colour/size stock
- Purchases and purchase-bill OCR
- Expenses
- Production tracking
- Reports
- Local encrypted daily backups
- PIN/biometric lock
